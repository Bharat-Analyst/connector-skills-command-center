Listing standard

One template for every connector, skill and plugin listing, written as eight checks a script can run. Every listing is audited against it, the most-viewed broken listings are rewritten first, and every new release must pass all eight before launch.

The template

FieldRule
TitleProduct name only, up to 30 characters. No "Connector", "MCP", "Integration", "Plugin", "Skill", no superlatives, no all caps.
One-line summaryOne sentence, up to 90 characters, ending in a period. Leads with what the user can do, not with the company's name.
Capabilities3–5 bullets, each starting with a capitalized verb, up to 60 characters.
PermissionsAlways stated (e.g. "Read", "Read and write (pages you can already access)").
Required connectorsAlways stated; "None" when there are none.
"Try asking"3+ prompts a user could paste, 15–80 characters each.
AuthorAlways shown.
AttributionPorts name the source repo, the creator's handle and the license: "Ported from owner/repo by @creator (MIT)".
