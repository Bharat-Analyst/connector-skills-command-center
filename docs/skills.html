How a port ships

1. Package

One folder per skill: SKILL.md (instructions + attribution), listing.json (marketplace copy), qa_log.md (every test prompt and result).

2. Pull request

The folder goes to the marketplace repo as a PR. The GitHub export workflow runs the license, attribution and listing-template checks; a failing check blocks the merge.

3. Launch

Merge exports the skill to the marketplace. Launch notes credit the creator by handle and link the source repo, the same day.

Future scope: first-party plugins

First-party plugins use the same path. A subject-matter expert writes the SKILL.md recipe, we run the same QA prompts, and the listing goes through the same template checks. Only the attribution line changes ("Built by the Marketplace team with team name").
